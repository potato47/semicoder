## 想做什么，就装一个小应用

翻译一段文字，记录一个想法，或者用模型完成自己的工作流。麻辣烫把共用的模型服务、KV 存储和 UI 组件放在宿主里，插件专注自己的交互与业务。

侧边栏切换应用，右侧整个空间交给当前插件。插件可以是翻译工具、编辑器或表单，不必长成聊天窗口。

## 现在可以做什么

- **译文**：选择自己的模型，流式翻译、取消生成、查看运行历史。
- **模型服务**：配置 API Key / Token、自定义 OpenAI-compatible 服务，或通过官方浏览器授权连接 ChatGPT 订阅。
- **应用中心**：安装、启停和卸载可信插件；从官方或自定义市场安装、手动更新插件，保留 npm / Git / 本地归档入口。
- **窗口置顶**：标题栏图标切换当前原生窗口置顶，便于边看边用。
- **统一界面**：Base UI 公共组件，浅色、深色与跟随系统；默认、GitHub 和自定义配色，插件继承主题。
- **页面与数据**：插件可选择保留切页状态，长期数据通过 KV 保存。
- **开发与自动化**：CLI 创建 notes / model 示例项目，检查、构建和打包独立插件。

## 从第一次翻译开始

先 [安装或构建麻辣烫](/malatang/docs/installation)，从「应用中心 → 插件市场」安装译文，再在「设置 → 模型服务」添加模型。打开「译文」，选择模型、输入文字、开始翻译。没有配置时不会产生模拟结果。

还不想配置模型，也可以在应用中心安装随手记，先体验插件与本地存储。

## 给插件开发者

插件默认导出 React 页面，通过 `@semicoder/malatang-sdk` 获取模型、任务和 KV。后端可注册带输入 schema 的业务方法，UI 组件与 React 运行时由宿主共享。

从 [第一个插件](/malatang/docs/plugin-development) 开始，继续阅读[插件结构](/malatang/docs/plugin-manifest)、[前端 API](/malatang/docs/plugin-client-api)、[后端 API](/malatang/docs/plugin-backend-api)、[UI 组件](/malatang/docs/plugin-ui)、[浮层与反馈](/malatang/docs/plugin-ui-overlays)、[样式主题](/malatang/docs/plugin-styling)和[构建分发](/malatang/docs/plugin-distribution)。[SDK 0.3.1 已发布 npm](https://www.npmjs.com/package/@semicoder/malatang-sdk/v/0.3.1)。CLI 创建的项目自带 SDK 快照，可脱离源码 workspace 开发；旧 SDK 0.2 及更早插件需迁移并重新构建。

## 当前边界

当前是 **0.4.2**，支持 macOS 14+ / Apple Silicon。插件按可信本地代码运行，具有本机代码执行能力，不是强隔离沙箱。用户内容在调用模型时会发送到所选服务商，并非离线 AI。ChatGPT 凭证明文保存在受限本地文件，不再访问钥匙串；从旧版升级需要重新登录并添加订阅模型。

工具注册与调用、预设 agent loop、调研应用、其他服务商订阅登录和插件自动升级尚未实现。不要把规划中的能力当成当前功能。

本页是麻辣烫官网。**0.4.2（Build 6）已发布**，[下载与安装](/malatang/docs/installation) 提供正式 DMG、校验文件及同版本共仓源码构建步骤。本次取消内置插件，官方翻译与随手记 0.1.0 已上架。升级前在旧版卸载手动安装插件，再用完整 DMG 替换；不迁移旧安装记录，模型、凭证、KV 和历史不主动清除。底层框架介绍见 [FIA](/fia)。
