## 记录构建，也让作品被使用

Semicoder 是「新手程序员」的个人网站。这里集中介绍 [FIA 桌面框架](/fia) 与 [麻辣烫插件应用](/malatang)，提供安装入口、使用指南和开发文档，也保留博客来记录过程。

## 内容各有归属

每个项目拥有独立主页、分组文档和项目内搜索。介绍说明解决什么问题，安装页给出真实可获取的版本，文档帮助读者从第一次运行走到自己的实现。

项目内容以 Markdown / MDX 在仓库中维护，稳定 ID 关联评论，URL 可以独立演进。公开页面、RSS、sitemap 和搜索在构建时生成，草稿不会进入生产内容。

## 技术实现

TanStack Start 与 React 提供页面和路由，Cloudflare Assets 提供公开内容，Workers 与 D1 处理登录、评论及审核，Bun 组织构建与检查。页面支持浅色、深色与移动端阅读。

本站项目介绍与文档已使用实际项目资料；博客中仍有明确标注的示例文章。登录、评论与部署的可用性取决于运行环境配置。

从 [快速开始](/semicoder/docs/getting-started) 了解本地开发，或阅读 [内容维护](/semicoder/docs/guides/writing) 了解如何添加内容。
