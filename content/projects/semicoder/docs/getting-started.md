## 准备环境

安装 Bun 和 Node.js，克隆仓库后安装锁定的依赖。

```bash
bun install --frozen-lockfile
bun run prepare
bun run db:local
bun run dev
```

## 浏览项目

首页连接博客、项目与文档。公开内容不依赖登录即可浏览。需要参与讨论时，通过 GitHub 登录。
