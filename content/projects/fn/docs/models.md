> 适用于 fn 0.4.4 / SDK 0.3.4，manifest 为 0.3。先按[安装指南](/fn/docs/installation)安装 fn；旧名称插件和旧应用数据不迁移。

## 一处配置，多个插件使用

模型服务由宿主管理。插件只拿到模型标识和公开配置，通过 SDK 调用；密钥不会通过业务 API 返回前端。

fn 0.4.4 使用固定版本 `@earendil-works/pi-ai@1.0.2` 的 provider 目录和协议适配，并支持自定义 OpenAI-compatible Chat Completions 服务。已发布 **0.4.4 / build 8** 完整 DMG，请按[安装指南](/fn/docs/installation)安装。预设目录随应用依赖更新，不代表所有服务已用真实账号逐一验收。

从较早的开发版本升级时，已确认的模型 ID 重命名会自动迁移；已从目录移除且没有明确替代项的模型会保留配置和历史，并提示重新选择。应用不会擅自换用其他模型，需在设置中重新选择可用项后再生成。

## API Key 或 Token

在「设置 → 模型服务」选择服务商、模型与必要参数，填写自己的凭证。Azure、Cloudflare、Bedrock 等服务可能需要额外的资源地址、账号 ID、区域或部署名称，以表单提示为准。

保存成功只表示配置完成，首次实际调用才能确认网络、额度与模型权限。模型名称可以自定义，同一服务商可以添加多份配置。

编辑时密钥不回显：留空保留原密钥，勾选清除才删除；更换服务商或 API 地址后需要重新填写。

## 自定义兼容服务

选择自定义 OpenAI-compatible 服务，填写 API Base URL、上游模型 ID 和 API Key。确认地址是服务商提供的 API 入口，不是网页聊天地址。插件继续选择宿主里的模型，不需要关心上游协议。

## ChatGPT 订阅

1. 点击 **Continue with ChatGPT**，在系统浏览器完成官方登录和授权。
2. 回到 fn，从账号实时提供的目录选择并添加模型。
3. 在译文或其他插件中选择该模型，界面会标明使用 ChatGPT plan。

模型固定绑定添加时的账号。设置里切换账号不会迁移已有模型；未获得订阅使用权限时不能生成，也不会自动改用 API Key 计费。可用模型和用量以该账号当时的目录与授权为准。

登录失败时优先重试原账号记录；「管理账号」支持重命名、移除单项和清理未完成登录。已连接账号需先退出，绑定模型需先移除。移除本地记录不等于注销远端账号。

## 凭证与数据

fn 将 ChatGPT 账号注册、当前账号及 access / refresh / ID token 明文保存到数据目录的 `chatgpt-auth.json`。目录权限为 0700、文件为 0600，完整写入、同步后原子替换；普通 API Key 和设置继续使用 `platform.json`。开发、预览与正式版分别保存。启动和账号操作不再访问钥匙串，官方浏览器登录与订阅授权仍由用户完成。不要分享凭证文件或包含它的数据备份。

fn 使用独立数据目录，不读取或迁移旧应用登录；首次需重新授权并添加模型。空文件、损坏或权限错误保留原文件并禁用 ChatGPT，见[排障说明](/fn/docs/troubleshooting#凭证文件错误)。

调用远端模型会发送提示词和输入内容到所选服务。插件按可信本地代码运行，不能把“不返回密钥的 API”理解为对恶意插件的安全隔离。

2026-10-15，本地 fn Dev 已完成新身份的官方 OAuth 授权，并通过官方译文插件使用 GPT-6-Luna 完成一次真实调用；正常退出重启后连接、模型及结果保留。此结果不代表正式应用已发布，也不覆盖令牌刷新 / 撤销或全部模型；可用性以实际账号授权及服务响应为准。
