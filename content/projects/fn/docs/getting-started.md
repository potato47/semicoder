## 先安装插件

首次启动进入「应用中心 → 插件市场」，通过“从地址安装”选择本地「译文」或「随手记」归档，步骤见[安装页](/fn/docs/installation#安装官方插件的本地归档)。应用不再内置插件；随手记无需配置模型。

## 配置模型

打开侧栏最下方的「设置」，进入「模型服务」。可以选择 API Key / Token 预设、自定义 OpenAI-compatible 服务，或点击 **Continue with ChatGPT** 在系统浏览器授权。

授权后还需要从该账号的可用目录选择模型并添加到宿主列表。fn 不内置免费的模拟模型，实际调用由你的模型服务或订阅提供，费用与额度以该服务为准。

细节见 [模型与账号](/fn/docs/models)。

## 完成一次翻译

1. 安装成功后打开侧栏的「译文」。
2. 选择已配置模型，填写原文与目标语言。
3. 开始翻译，查看流式结果；需要时取消任务。
4. 从历史中查看已保存的结果。

模型为空或账号失效时先回设置处理。切换模型配置会同步到插件；删除最后一个模型后，生成入口会停用。

## 体验随手记

按[安装页](/fn/docs/installation#安装官方插件的本地归档)打包并安装「随手记」。插件使用宿主 KV 保存笔记，不需要模型。

安装后点击打开，写下笔记并保存，再切换页面或重启检查持久化效果。插件卸载会保留 KV 与历史，重新安装相同 ID 的插件可以继续读取。

## 外观与页面状态

在「设置 → 外观」选择浅色、深色或跟随系统。偏好保存在本机，插件与原生标题栏共同切换。

主题统一在设置页切换。

提供默认、GitHub 和自定义配色。分别调整浅色 / 深色的强调色、背景与前景，即时预览后点击「保存配色」；取消或离开设置恢复已保存配色，「恢复默认」也需保存。文字对比度不足时提示调整。原生标题栏只跟随明暗模式，插件和弹出层继承内容区配色。

插件是否保留切页草稿由它的 `keepAlive` 声明决定。译文和新版随手记已开启，但刷新、退出和更新仍会销毁页面内存；需长期保留的数据必须主动保存。

## 将窗口置顶

点击标题栏浏览器入口左侧的置顶图标，让当前原生窗口保持在普通窗口上方。选中时图标填充高亮、提示改为“取消置顶”；再次点击恢复。

置顶按窗口独立生效，隐藏后再打开、后端重连会保留；关闭并销毁窗口或退出应用后重置。它不控制浏览器窗口，也不让窗口跨桌面显示。

## 在浏览器使用

标题栏最右侧提供“在浏览器中打开”。点击后可在本机浏览器中使用完整插件界面，同时保留原生窗口。模型、插件、KV 和主题共用同一后端；未保存的表单与草稿不会复制。

刷新可继续使用当前授权；重启或更新应用后需重新点击标题栏。应用菜单和托盘菜单可“断开浏览器连接”，立即撤销当前实例所有浏览器会话。地址与端口本身不授予 API 访问权限。

浏览器可使用原生文件选择、剪贴板和更新界面；直接访问钥匙串、屏幕捕获等高权限能力仍被拒绝。当前使用[本地构建](/fn/docs/installation)。
