## 恢复演练与性能边界

预发布导出快照恢复至独立本地 D1，修正导出语句的建表/插入顺序后导入成功。快照及恢复库均为 user 1、comment 1、audit 1，外键检查无违规。演练未覆盖远端新库切换和生产灾难恢复；生产数据库未被覆盖。后续在评论继续写入后，在线库计数高于该快照属于正常现象。

后台改为不含用户数据的预渲染界面，动态授权仍由服务端执行；观察到两个 `/admin` 请求 CPU 均为 1ms。优化后的预发布 23 次服务端函数采样 CPU 中位数约 11ms、最大 68ms，未记录失败。这不能证明长期满足免费版每请求 10ms 限制；真实流量需继续观察资源超限与错误率。
