# 产品与路线图

新手程序员（semicoder.dev）是中文个人技术门户。技术出版风、响应式布局、浅深色主题。内容仓库驱动，评论后台管理。

全站顶栏采用 icon +「新手程序员」的单行中文品牌，桌面高 60px、手机高 56px，随页面滚动离开视口。搜索、主题和登录入口集中在右侧；已登录时只显示头像，点击后展开账号操作。手机保留完整中文品牌，折叠导航与账号浮层互斥展开。首页采用独立的时间信息布局。

首版交付首页、博客、项目、每项目单版本文档、中文搜索、GitHub 登录评论和审核后台。包含 RSS、sitemap、隐私与评论规则。示例内容必须明确标记。

实施顺序：规范基线 → Workers 技术闭环 → 内容门户 → 评论审核 → 生产上线。

FIA 与麻辣烫已接入真实项目介绍、安装方式、使用和开发文档，统一从顶栏“项目”进入；本站介绍也改为实际内容。博客示例继续明确标注。后续可按需要补充文章、媒体管理、通知、工具应用与多版本文档，不自动增加付费服务。

上线门槛：质量检查、生产构建、Workers 权限测试、浏览器验证通过；配置真实域名、数据库、GitHub OAuth、Turnstile 和管理员 ID。真实登录及恢复演练须在拥有环境凭据后单独记录，不能由本地模拟代替。

项目根地址是文档 Home，使用原有项目介绍，与章节共享侧栏、本页目录和相邻章节。项目列表按类别展示简洁卡片，桌面两列、手机单列；不增加筛选或介绍区。独立文档概览和项目工具栏移除，原 `/<project>/docs` 返回 404；章节多级路径与搜索页的项目文档筛选保留。项目 Home 关闭评论，博客评论继续使用，沿用中文技术出版风格。内容集中在本站仓库维护，旧详情 URL 不提供兼容跳转。

2026-10-04 用户确认：移除全站独立文档入口与集合页，统一从项目进入；当时保留项目内部文档概览、章节导航及搜索；2026-10-07 的 Home 整合替代其中保留独立概览的决定，详见 ADR 0002。

## 时间首页

首页完整展示大时钟、公历日期、北京时间中国历法、今年的时间进度、时间坐标与传统节日。保留全站顶栏，页脚简化为版权、站点链接与 RSS 订阅按钮；原介绍插画、项目卡片、文章列表和行动入口已移除；博客、项目和各自文档仍通过导航访问。沿用浅深色主题，手机按单列阅读。按用户截图反馈移除顶部标题和刷新状态，以及四个分区的可见标题、编号、右侧说明和横向分割线；使用留白区分内容，保留具体数值标签。

主时钟使用 24 小时制，跟随设备本地时区，每秒更新；时间进度只显示今年，按实际本地起止时间计算；所有屏宽均以单条进度占满内容宽度。中国历法统一按北京时间计算，包含农历、闰月、干支年、生肖、时辰范围、当前与下一节气及倒计时。干支年与生肖在春节换年，节气在实际交接时刻切换。

时间坐标包含季度、年内日序、全年和剩余天数（不含今天）、ISO 周数及所属周历年、平闰年、UTC、ISO 8601 和 Unix 秒／毫秒时间戳。传统节日包含春节、元宵、清明、端午、七夕、中元、中秋、重阳、腊八和除夕；今日节日显示“就是今天”，下一个节日仅选未来日期，按北京时间日历天数倒计时，不表示放假调休安排。

全部模块默认展开，不提供显隐、时区或 12/24 小时设置。时间来自设备，不执行网络校时，也不请求地理位置。禁用 JavaScript 时保留页面说明与导航，并提示开启脚本查看实时信息。

全站页脚取消介绍标语与说明区，“订阅更新”按钮移至底栏右侧，替换“用热爱构建”；手机端也保留订阅入口。底栏与上方内容之间保留一条细分割线，颜色随浅深色主题变化。首页底部不再显示设备时间来源与节日安排说明。
