# 产品与路线图

新手程序员（semicoder.dev）是中文个人技术门户。技术出版风、响应式布局、浅深色主题。内容仓库驱动，评论后台管理。

首版交付首页、博客、项目、每项目单版本文档、中文搜索、GitHub 登录评论和审核后台。包含 RSS、sitemap、隐私与评论规则。示例内容必须明确标记。

实施顺序：规范基线 → Workers 技术闭环 → 内容门户 → 评论审核 → 生产上线。

后续：真实内容替换、R2 媒体管理、通知、工具应用、多版本文档。首版不建设多人投稿、支付和 AI 助手。

上线门槛：质量检查、生产构建、Workers 权限测试、浏览器验证通过；配置真实域名、数据库、GitHub OAuth、Turnstile 和管理员 ID。真实登录及恢复演练须在拥有环境凭据后单独记录，不能由本地模拟代替。

项目主页与文档使用统一顶层项目路径。项目文档支持分组、多级路径、概览页和限定项目的中文搜索，保留原有中文技术出版风格。内容集中在本站仓库维护，旧详情 URL 不提供兼容跳转。
